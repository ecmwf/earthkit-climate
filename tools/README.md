# Maintenance and Code Generation Tools

This directory contains internal maintainer utilities for `earthkit-climate`. These scripts are intended for developers maintaining the repository and are not distributed in binary wheels or packages installed via `pip` or `conda`.

## Code Generator (`tools/codegen.py`)

`earthkit-climate` provides static, typed wrapper functions for climate indicators provided by computational engines such as `xclim` and `icclim`. Generating these wrappers statically ensures:

1. Full IDE autocompletion, hover documentation, and Language Server Protocol (LSP) support.
1. Complete static type checking via `mypy` and `pyright`.
1. Comprehensive API documentation generated by Sphinx and AutoAPI.
1. Minimal package import overhead at runtime.

### Usage

Run code generation using `uv`:

```bash
export PYTHONPATH="."

# Generate all indicators (both xclim and icclim)
uv run python tools/codegen.py --all

# Generate only xclim indicator wrappers
uv run python tools/codegen.py --xclim

# Generate only icclim indicator wrappers
uv run python tools/codegen.py --icclim
```

Generated files are placed in `src/earthkit/climate/indicators/xarray/`:

- `_xclim_atmos.py`
- `_xclim_land.py`
- `_xclim_seaice.py`
- `_icclim.py`
